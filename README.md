# CareSafe MVP v0.1 — 데모 가이드

## 바로 실행하는 법

1. 이 폴더의 `index.html`을 더블클릭 → 기본 브라우저에서 열림
2. 시연 시: 브라우저 탭 **3개**를 같은 창에서 열어두면 더 극적
   - 탭 A: `guardian.html` (보호자 자녀 스마트폰 화면)
   - 탭 B: `admin.html` (병원 퇴원지원팀 대시보드)
   - 탭 C: `simulator.html` (시니어가 착용한 기기)

## 시연 시나리오 (3시 미팅용 · 5분)

### ① 먼저 보여줄 화면 — 3탭 병렬
- **보호자 탭**: 김영자 어머니(78세) 정상 상태. 오늘 오전 체크인 완료. → "자녀가 출근해도 부모님 상태를 계속 볼 수 있다"
- **관리자 탭**: 퇴원지원팀이 시범 5가구 실시간 모니터링. 거점 병원 파이프라인 테이블에 **분당차병원 4/17 15시 미팅(오늘)** 표시. → "병원 입장에서 얻는 데이터와 협력 구조"

### ② 긴급 상황 시연
1. **시뮬레이터 탭**에서 "🆘 SOS" 빨간 버튼 누름
2. **보호자 탭**에서 즉시 토스트 알림 + 상단 상태가 빨간색 "위급"으로 변경, 펄스 애니메이션
3. **관리자 탭**에서도 피드에 실시간 추가, KPI "위급 대응 대기 1명"으로 증가

### ③ 낙상 감지 시연
- 시뮬레이터의 "⚠️ 낙상 감지 (가속도계)" → 가속도 9.2G 이벤트 생성 → 보호자 토스트

### ④ 일상 운영 시연
- "💊 복약 체크 누락" → 주의 알림 (노란색) → 보호자가 전화로 챙길 수 있음
- "🟢 활동 감지" → 정상 신호 → "평범한 하루"도 데이터로 안심 제공

### ⑤ 초기화
- 시뮬레이터 페이지 최하단 "🔄 데모 초기화" 버튼

## 기술 메모

- 순수 HTML/CSS/JavaScript. 서버·빌드 없음.
- 탭 간 실시간 동기화는 `BroadcastChannel` + `localStorage`.
- 모든 상태는 브라우저 로컬에 저장 (개인정보 외부 전송 없음).
- 모바일 반응형 (보호자/시뮬레이터는 모바일 우선, 관리자는 데스크톱 우선).
