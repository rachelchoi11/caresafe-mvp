CareSafe 개인정보 처리방침

시행일: 2026-05-11 (베타) · 최종 개정: 2026-05-11
⚠️ 베타 단계 안내
본 처리방침은 베타 단계 임시본입니다. 정식 출시 전 PIPA(개인정보보호법) 및 의료법 검토 후 갱신됩니다. 의료정보는 민감정보로 분류되어 별도의 명시적 동의 후 처리됩니다.

1. 처리하는 개인정보 항목

보호자 (회원) 정보
  • 이름·이메일 (Google 로그인을 통해 자동 수집)
  • 프로필 사진 URL (Google 로그인 제공값)
  • 서비스 이용 기록 (로그인 시각·알림 응답 시간)
돌봄대상자 (수혜자) 정보 — 보호자가 등록
  • 이름·생년·성별·거주지 (식별 정보)
  • 혈액형·알레르기·복용약·기저질환·이식 의료기기 등 (민감정보)
  • 주치의·응급 연락처
  • SOS 호출·활동 신호 이력
  • DNR·사전연명의료의향서 등록 여부

2. 처리 목적

  1. 보호자가 돌봄대상자 상태를 실시간 확인할 수 있도록 알림·이력 제공
  2. 응급 상황에서 발견자(119·이웃·요양보호사)에게 환자 기본 정보 표시 (응급카드)
  3. AI 보조 기능 — 대응가이드 생성, 응급카드 항목 정리, 알림 우선순위 분류
  4. 서비스 개선·통계 (식별 정보 제거 후)

3. 처리 및 보관 기간

  • 회원 정보: 회원 탈퇴 시까지 보관, 탈퇴 즉시 파기 (관계 법령상 의무 보관분 제외)
  • 돌봄대상자 의료정보: 회원 탈퇴 또는 보호자의 삭제 요청 시까지
  • 알림·이력 데이터: 최대 1년 (이후 익명화 통계로만 보존)
  • AI 처리 캐시: 30일 (반복 호출 비용·지연 감소 목적)

4. 제3자 제공

회원의 동의 없이 제3자에게 개인정보를 제공하지 않습니다. 단, 다음의 경우 예외:

  • 법령에 따라 수사 기관·법원 등이 요청한 경우
  • 응급 상황에서 보호자의 명시적 요청으로 119·의료기관에 정보 전달
  • 응급카드 QR/NFC를 통해 발견자가 접근하는 경우 (회원이 의도한 노출)

5. 처리 위탁

다음 외부 서비스에 일부 처리를 위탁합니다. 위탁 시 보안·비밀유지 의무가 적용됩니다.

  • Google Firebase (Google LLC) — 데이터 저장·실시간 동기화·인증. 데이터 위치: 싱가포르.

AI 보조 기능에 대한 안내

본 서비스의 AI 대응가이드·안부 톡 추천 등 AI 기능은 운영 단계에 외부 AI API를 호출하지 않습니다. AI가 생성하는 응답은 모두 개발 단계에서 사전 생성되어 정적 콘텐츠로 앱에 포함됩니다. 결과적으로 회원·돌봄대상자의 의료정보가 OpenAI 등 외부 AI 서비스로 전송되지 않습니다.

변경 이력: 초기 베타에서는 OpenAI API 위탁이 명시되었으나, 보안·프라이버시 강화를 위해 ‘사전 생성 + 런타임 매칭’ 아키텍처로 전환됨 (2026-05-11).

6. 국외 이전

Google Firebase는 싱가포르 리전에 데이터를 저장합니다. 회원은 가입 시 이 국외 이전에 동의하는 것으로 간주됩니다.

7. 회원의 권리

  • 본인·돌봄대상자 정보의 열람·정정·삭제 요청
  • 처리 정지 요청
  • 동의 철회 (단, 철회 시 서비스 이용이 제한될 수 있음)
  • 요청 방법: 앱 내 설정 또는 support 이메일

8. 보안 조치

  • Firebase Security Rules로 인증된 보호자만 자신의 돌봄대상자 정보 접근
  • 의료정보 전송 시 HTTPS 암호화
  • AI API 호출 시 비식별화 가능 항목은 사전 익명화
  • 접근 권한 최소화 원칙 (운영진도 필요 시에만 접근)

9. 개인정보 보호 책임자

베타 단계: 서비스 운영 책임자 (출시 시 별도 지정) · 연락: support@caresafe.example

10. 변경 고지

본 처리방침이 변경될 경우 시행 7일 전 앱 내 공지로 안내합니다. 중요한 변경은 회원에게 직접 알림으로 전달합니다.
