외부 디바이스 통합 가이드

실제 IoT 디바이스에서 Firebase RTDB로 직접 알림 POST하는 패턴:

POST https://caresafe-mvp-default-rtdb.asia-southeast1.firebasedatabase.app/alerts.json?auth=<ID_TOKEN> Content-Type: application/json { "uid": "u1", "type": "sos", "level": "danger", "text": "🆘 LTE-M 버튼 눌림", "time": 1747000000000, "location": { "address": "서울 강남구", "lat": 37.4979, "lng": 127.0276, "accuracy": 50, "source": "device" } } # 응답: { "name": "-Oxxx..." } ← Firebase 자동 생성 키

⚠️ ID_TOKEN은 Firebase Authentication 또는 Service Account로 발급. 운영 시 Cloud Function 프록시 권장 (보안·rate limit).

3️⃣ 애플 워치 단축어 (Shortcuts) 우회 우회 가능

iOS 단축어 앱으로 워치에서 직접 우리 webhook 호출하는 방법. SOS 알림 흉내 가능.

  1. iPhone → 단축어 앱 → 새 단축어 만들기
  2. “URL의 내용 가져오기” 동작 추가
  3. URL: 위 webhook 주소 (Firebase REST)
  4. 방식: POST · 본문: JSON (uid·type 등)
  5. 단축어 우상단 ⚙️ → “Apple Watch에서 사용” ON
  6. 워치 컴플리케이션 또는 단축어 앱에서 SOS 트리거

한계: 단축어는 Wi-Fi/LTE 연결 + 폰 근거리 필요. 워치 단독 동작은 정식 앱 필요.

3️⃣-B 애플 워치 헬스 데이터 (낙상·심박·ECG·SpO2) 간접만

애플 워치 자체 센서·기능 → CareSafe 연동 가능성:

워치 기능직접 연동현실적 경로
🍎 낙상 감지 (Series 4+) ❌ 워치 → 119 자동 신고 + 응급 연락처에 SMS (Apple 기본)
→ 응급 연락처에 보호자 등록만 하면 메시지 수신 가능
❤️ 심박 비정상 알림 ❌ 워치 자체 알림 → 단축어로 우리 webhook에 수동 push
또는 HealthFit·Cardiogram 같은 3rd party 앱이 HealthKit 데이터를 외부 webhook으로 자동 전송
🫁 SpO2 (혈중산소) ❌ 위와 동일 — HealthKit 경유 3rd party 앱
⚡ 심전도(ECG) ❌ 측정 후 PDF 내보내기 → 보호자 공유 (수동)
🛌 수면 분석 ❌ HealthFit 등으로 일간 요약 webhook 전송 가능
🆘 워치 SOS 호출 (사이드 버튼 길게) ❌ 워치 → 119 자동 신고 + 응급 연락처 SMS — Apple 기본 동작. CareSafe 직접 통합 ❌

💡 가장 현실적인 통합 패턴 3가지

A. Apple 기본 응급 연락처 활용 (0원, 즉시)

  • 워치/폰 설정 → 의료ID·응급 연락처에 보호자 번호 등록
  • 워치 낙상 감지·SOS 호출 시 119 자동 + 보호자에게 SMS 자동 발송
  • CareSafe 안 거치지만 가장 안전한 1차 안전망

B. 3rd party 브릿지 앱 (HealthFit·Health Auto Export 등)

  • 유저가 앱 설치 + HealthKit 권한 부여
  • 심박·SpO2·수면·걸음 데이터를 외부 webhook으로 자동 전송
  • 우리 Cloud Function이 받아서 알림·차트화 (v1.0+)
  • 장점: 우리 native 앱 개발 없이 워치 데이터 수신
  • 한계: 사용자가 별도 앱 설치 필요. 실시간 ✗ (배치 push)

C. CareSafe iOS 네이티브 앱 (v2.0+)

  • HealthKit 직접 권한 → 모든 워치 데이터 실시간 접근
  • 이상치 자동 감지·보호자에게 즉시 알림
  • 비용: 앱 개발·App Store 심사·HealthKit 의료 데이터 정책 검토
⚠️ 워치 SOS·낙상 감지 자체는 Apple 기본 기능이라 CareSafe 우회 ❌.
파일럿 단계 권장: 보호자가 부모님 폰·워치의 의료ID/응급 연락처에 보호자 번호 등록 → Apple 자동 알림망 활성화. CareSafe는 이와 별개의 보조 안전망.

4️⃣ 갤럭시 워치 Tasker 우회 우회 가능

Android Tasker (유료 앱)로 워치 입력 → HTTP POST 자동화. Wear OS 워치도 가능.

  1. 안드로이드 폰에 Tasker 설치
  2. ‘새 작업’ → HTTP POST 동작 추가 (Net 카테고리)
  3. URL·헤더·본문 위 webhook 형식대로 설정
  4. 트리거: 워치 버튼·음성 명령·앱 알림 등
  5. Wear OS 앱(AutoWear)으로 워치에서 직접 트리거
