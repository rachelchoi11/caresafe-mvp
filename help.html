CareSafe 사용 가이드

처음 사용하시는 보호자(자녀)를 위한 5분 안내 · v0.2 베타
⚠️ 본 서비스는 베타 단계입니다. 의료 진단·치료를 대체하지 않으며, 응급 상황에서는 반드시 119 신고를 우선해야 합니다.

1 가장 먼저 — 부모님 등록

보호자 앱 메인 화면의 ‘돌봄 대상자 선택’ 카드 아래 ➕ 부모님 추가 버튼을 누르세요.

  1. 기본 정보: 이름·나이·성별·혈액형 (필수)
  2. 응급 연락처: 1순위는 보호자 본인. 2순위로 다른 가족 추가 권장
  3. 의료 정보: 알레르기·복용약·기저질환·주치의 (강력 권장)
  4. 고급 정보: DNR·최근 이력·이식기기 등 (선택, 응급실에서 중요)
💡 처방전·약봉투 사진을 미리 받아두세요. 약물명·용량을 직접 보고 입력하는 게 정확합니다.

2 응급카드 (QR / NFC) 발급

부모님 등록이 완료되면 ‘응급정보 카드 (QR)’ 영역에서:

  • 🔳 QR 카드 보기 → 응급카드 페이지 QR 표시 (스캔하면 응급정보 페이지 열림)
  • ↗ 응급카드 페이지 열기 → 직접 페이지 확인 (인쇄·PDF 저장 가능)
  • 인쇄 → 명함 크기로 출력 → 부모님 지갑·냉장고·현관에 부착
💡 NFC 카드 (실물 PVC 카드)는 출시 후 별도 발주 안내 예정. 당분간은 QR 인쇄본을 추천합니다.

3 알림이 오면

부모님 기기에서 신호가 오면 보호자 앱 상단 상태 카드가 녹색 정상·노랑 주의·빨강 위급 으로 바뀝니다.

  1. 최근 알림 카드에서 항목을 탭하면 대응가이드 모달이 열림
  2. 알림 유형 + 부모님 의료 정보에 맞춰 단계별 행동 가이드 자동 표시 (예: 와파린 복용자 + SOS → 출혈 위험 강조)
  3. 가이드의 단계대로 행동 (전화·확인·119)
⚠️ 위급(빨강) 알림 = 즉시 부모님께 전화 후 응답 없으면 119. 가이드는 보조 자료이지 의사 결정을 대신하지 않습니다.

4 부모님께 안부 보내기

‘부모님께 안부 보내기’ 카드에서 💬 안부 톡 작성 클릭:

  • AI가 부모님 최근 상태에 맞춰 3개 톤 추천 (따뜻·일상·챙김)
  • 마음에 드는 톤 선택 → 직접 편집 가능
  • 💬 문자로 보내기 또는 📋 카톡용 복사
💡 평상시·복약 누락 후·위급 회복 후·무소식 상황별로 추천 어조가 다릅니다.

5 매주 안전 체크 (3분)

‘이번 주 안전 체크’ 카드 — 6개 항목으로 부모님 댁 환경 점검:

  • 욕실 미끄럼방지 매트 / 야간 동선 조명
  • 1주일 약통 정리
  • 응급카드 인쇄본 부착 / 응급 연락처 가족 공유
  • 주 2회 이상 영상통화

매주 일요일 또는 방문 시 한 번씩 체크 권장.

6 무소식이 길어지면

부모님 신호가 24시간+ 없으면 화면 상단에 노란 ‘무소식 알림’ 배너가 자동 표시됩니다.

  • 외출·여행 가능성도 있으니 먼저 전화
  • 응답 없으면 가까운 가족·이웃 방문 부탁
  • 30분+ 미응답 시 119 신고 고려

7 계정 설정·로그아웃

하단 탭의 ⚙️ 설정:

  • 등록한 부모님 목록·QR 발급 여부 확인
  • 등록 시니어 삭제 (✕ 버튼)
  • 이용약관·개인정보·민감정보 동의 안내 보기
  • 로그아웃·계정 탈퇴 (PIPA 권리)

? 자주 묻는 질문

Q. 부모님께 별도 앱을 설치해야 하나요?
A. 보급형은 물리 SOS 버튼만 필요합니다. 부모님 폰에 앱 설치 ❌.

Q. 119에 자동 신고되나요?
A. 아니요. 응급 상황 판단·신고는 보호자가 직접. 자동 신고는 응급의료법상 금지.

Q. 부모님 의료 정보가 외부로 새지 않나요?
A. AI 응답은 미리 만들어둔 답을 매칭 사용 — 운영 시 외부 AI에 부모님 정보 전송 ❌. 데이터는 Google Firebase (싱가포르)에 암호화 저장, 본인만 열람.

Q. 응급카드 QR을 누가 봐도 부모님 정보가 노출되나요?
A. 토큰을 알아야 접근 가능 (지갑 안 카드 발견 시). 응급 상황 식별·연락 목적의 제한된 정보만 표시.

Q. 베타 단계의 의미는?
A. 정식 출시 전 시범 운영. 법무·의료 자문 결과 반영·일부 기능 강화 예정.
